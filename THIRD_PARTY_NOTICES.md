# Provenance and redistribution status

Rivora is an independently branded integration, not an official Frappe or Nesscale product.

The mobile client and permission-scoped server adapter were carried forward from the local ESS Mobile project. The supplied reference backend source is included within server/rivora with its notices. Vendor APK/XAPK and vendor logos are not used as Rivora branding. New Rivora session endpoints, metadata and vector mark were added on 2026-10-28. This is not a claim that all project code has exclusive or verified ownership.

The previous adapter carried a license headed GPL v3 with a 2023 Nesscale Solutions Private Limited copyright notice and nonstandard text. That exact file is preserved in LICENSES/legacy-extras-license.txt. Its text differs from the standard GNU GPL. The reference backend also declared MIT in hooks, conflicting with its license file. A rename does not resolve this discrepancy.
